# Halcyon new tab

Open `chrome://extensions`, enable Developer mode, choose **Load unpacked**, and select this `extension/` directory. Open a new tab to see the Halcyon homepage with the Google services row, the **Tìm trên Google** field (it opens Google's results page directly and needs no `search` permission) and the calendar card with the lunar date, the zodiac animals and the weather (Open-Meteo, city chosen by the reader).

The background worker saves `data/radar-window.json` in `chrome.storage.local` on install, startup, and every 30 minutes. It restores the refresh alarm when the worker starts if Chrome dropped it. The page draws the saved snapshot first. When online, it loads `data/radar-ui.json`, Arena rankings, feed images, and editor picks from the live site. Feed images and editor picks fall back to their packaged copies when unavailable; saved stories remain readable offline. On a first install without a saved snapshot, the homepage's empty state appears until the first worker refresh completes. From 768 px wide, the first screen shows the day's picture (`nen.js`): today's entry in the live `nen/lich.json` (Asia/Bangkok), else the latest earlier one; the last picture that loaded is kept in Cache Storage for offline tabs, and `anh/nen-du-phong.webp` is shown when neither is available. Narrower windows never download it. Reader preferences are stored under the extension origin and start empty.

The homepage files under `site/` are the source. After a site UI change, run `python extension/sync-site.py` from the repository root. The script copies the homepage's CSS, modules, fonts, image manifest, and editor picks, then generates `extension/newtab.html`, `extension/feed.js`, `extension/arena.js`, and `extension/story.js` with the MV3 data and link adaptations. Review the generated diff and run the tests; the extension-specific search and cache files remain separate. The script fails if an expected source anchor changes or the generated page contains an inline or remote script or relative page/data link.

Run focused tests with `python -m unittest discover -s tests -p "test_extension_shell.py"` and the full suite with `python -m unittest discover -s tests -p "test_*.py"`. The visual walk uses `node tests/fixtures/extension-walk.js`; it requires Puppeteer and local Chrome.

To regenerate the Halcyon extension icons and Chrome Web Store art, run `python brand/build-assets.py` and then `python brand/export-png.py` from the repository root. The build command writes the 16/32/48/128 SVG icons and 440×280 promo tile; the export renders the dimension-checked PNG icons and promo tile in `brand/assets/store/`, then copies the four extension icons into `extension/icons/`. Store screenshots are generated with `node brand/store-shots.js` after syncing the site into the extension. That command installs this folder unpacked in headless Chrome, waits for its worker to save the live `radar-window.json`, fails if the data is older than three hours or the new tab has no cards, and writes the 1280×800 light and dark shots to `store/anh/`. It requires local Chrome, Node, and a Puppeteer (or `puppeteer-core`) 24 release with `browser.installExtension` (last run with 24.40). The upload steps are in [store/SUBMIT.md](store/SUBMIT.md).
