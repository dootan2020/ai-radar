# ai·radar new tab

Open `chrome://extensions`, enable Developer mode, choose **Load unpacked**, and select this `extension/` directory. Open a new tab to see the ai·radar homepage and the **Tìm trên web** field. The field uses Chrome's configured default search engine.

The background worker saves `data/radar-window.json` in `chrome.storage.local` on install, startup, and every 30 minutes. It restores the refresh alarm when the worker starts if Chrome dropped it. The page draws the saved snapshot first. When online, it loads `data/radar-ui.json`, Arena rankings, feed images, and editor picks from the live site. Feed images and editor picks fall back to their packaged copies when unavailable; saved stories remain readable offline. On a first install without a saved snapshot, the homepage's empty state appears until the first worker refresh completes. Reader preferences are stored under the extension origin and start empty.

The homepage files under `site/` are the source. After a site UI change, run `python extension/sync-site.py` from the repository root. The script copies the homepage's CSS, modules, fonts, image manifest, and editor picks, then generates `extension/newtab.html`, `extension/feed.js`, `extension/arena.js`, and `extension/story.js` with the MV3 data and link adaptations. Review the generated diff and run the tests; the extension-specific search and cache files remain separate. The script fails if an expected source anchor changes or the generated page contains an inline or remote script or relative page/data link.

Run focused tests with `python -m unittest discover -s tests -p "test_extension_shell.py"` and the full suite with `python -m unittest discover -s tests -p "test_*.py"`. The visual walk uses `node tests/fixtures/extension-walk.js`; it requires Puppeteer and local Chrome.

To regenerate the LogosTab extension icons and Chrome Web Store art, run `python brand/build-assets.py` and then `python brand/export-png.py` from the repository root. The build command writes the 16/32/48/128 SVG icons and 440×280 promo tile; the export renders the dimension-checked PNG icons and promo tile in `brand/assets/store/`, then copies the four extension icons into `extension/icons/`. Store screenshots are generated separately with `node brand/store-shots.js` after the extension is renamed to LogosTab in the separate rename PR. That command installs the extension in headless Chrome, waits for today's live `radar-window.json`, and fails if the data is stale or the new tab has no cards. It requires local Chrome, Node, and Puppeteer resolvable as `puppeteer`.
